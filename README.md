# Подбор перспективной ниши для Ozon/Wildberries

Учебный проект по методике поиска и оценки товарной ниши для маркетплейсов: от фильтрации сырых данных аналитики до готового кандидата с посчитанной юнит-экономикой и черновым УТП.

## О данных

Данные в проекте **синтетические** — сгенерированы по структуре, аналогичной реальной выгрузке MPStats, с реалистичным распределением спроса (не равномерным, а с длинным хвостом: у большинства карточек низкий оборот, у нескольких — высокий). Доступа к платной аналитике на момент подготовки не было.

Код спроектирован так, что при подключении реального экспорта из MPStats меняется один блок (источник данных) — вся остальная логика фильтрации, сравнения площадок и юнит-экономики отрабатывает без изменений.

## Что делает проект

1. **Фильтрация ниши** — пороги по цене, обороту, % выкупа и числу продавцов рассчитаны через квантили от реального распределения данных, а не заданы произвольно.
2. **SQL + pandas параллельно** — вся ключевая логика продублирована на обоих инструментах для сверки результатов.
3. **Сравнение Ozon vs Wildberries** — поиск ниш с перекосом между площадками (окно возможностей на менее занятой площадке).
4. **Юнит-экономика** — функция расчёта максимальной закупочной цены под целевую рентабельность, с учётом комиссии площадки, рекламы, логистики и риска брака.
5. **Детект накрутки/самовыкупов** — эвристика на основе соотношения отзывов к заказам, проверенная на контролируемом эксперименте.
6. **УТП и отстройка** — разбор конкретных ниш с предложением по дифференциации товара.

## Ключевые находки

- Из 120 карточек статистически обоснованный фильтр (квантили, откалиброванные под сам датасет) оставил короткий список кандидатов.
- Комиссия маркетплейса — крупнейшая статья расходов в юнит-экономике (для среднего ценового сегмента 2026 года — 35–55%, а не устаревшие 15%, которые часто берут по умолчанию).
- Сравнение ниш стоит вести в % от цены продажи, а не в рублях — так виден реальный запас прочности сделки, независимо от абсолютной цены товара.
- Эвристика детекта накрутки поймала 5 из 5 искусственно смоделированных аномалий в контролируемом эксперименте, но даёт заметный процент ложных срабатываний на органических данных — используется как сигнал для ручной проверки, а не как автоматический фильтр.

## Структура репозитория

```
├── notebooks/
│   └── niche_analysis.ipynb   — основной ноутбук со всем анализом (Google Colab / Jupyter)
├── docs/
│   ├── glossary.md            — теория: статистика (квантили) и экономика (юнит-экономика) простым языком
```

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook notebooks/niche_analysis.ipynb
```

Либо загрузить `notebooks/niche_analysis.ipynb` напрямую в [Google Colab](https://colab.research.google.com) — все зависимости (pandas, numpy, matplotlib, sqlite3, openpyxl) доступны там по умолчанию.
